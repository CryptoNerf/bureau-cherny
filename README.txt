БЮРО — исходные файлы сайта

Актуальная опубликованная версия от 20 октября 2026 года.

Состав:
index.html — текст и структура страницы.
style.css — оформление и адаптация.
site.js — вывод контактов.
.htaccess — редирект на https://b-u-r-o.com (без www) для хостинга reg.ru.
tour/ — пример 3D-тура (экспорт 3DVista), встроен на страницу через iframe.

Запуск:
Распакуйте архив и откройте index.html в браузере.
Сборка, npm и внешние зависимости не нужны.

Размещение:
Сайт размещён на хостинге reg.ru (Хост-0), папка www/b-u-r-o.com.
Загрузите туда index.html, style.css, site.js, .htaccess и папку tour.
index.html должен быть входной страницей. DNS домена обслуживает Cloudflare
(режим DNS only): A b-u-r-o.com → IP хостинга, CNAME www → b-u-r-o.com.

Поведение:
Один белый экран без прокрутки. По центру — название, окно 3D-тура и
информационный блок. Тур управляется мышью или касанием, есть полноэкранный
режим. Автозапуск фоновой музыки в туре отключён (убран вызов playAudioList
в tour/script_general.js и tour/script_mobile.js). Курсор обычный.
Телефон и почта отсутствуют в исходном HTML и подставляются скриптом,
чтобы их не собирали спам-боты; блок контактов помечен data-nosnippet.
Контакты представлены обычным текстом без кликабельных ссылок.

Тур временный: экспорт сделан в учебной версии 3DVista и показывает водяной
знак «Created by 3dvista Academic». Настоящий тур нужно экспортировать из
коммерческой версии и заменить содержимое папки tour.

Служебные файлы хостинга и учётные данные в архив не включены.
